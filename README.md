# Samba Scout releases

Downloads and updates for Samba Scout, a scouting app for Football Manager 2012 on Mac.

Download the latest disk image from [Releases](https://github.com/Gloyns/samba-scout-releases/releases), drag Samba Scout into Applications, then right-click it and choose Open the first time.

Once installed, Samba Scout checks this repo once a day and offers updates inside the app. `latest.json` describes the newest version.
